# Event Promotions Platform

Plataforma para la confirmación de asistencia de clientes a un evento anual de promociones.

La aplicación permite a los clientes:

- Confirmar su participación en el evento.
- Seleccionar servicios de interés.
- Seleccionar productos de interés.
- Obtener descuentos según las reglas establecidas.

## Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- TypeScript
- Express

### Database
- PostgreSQL
- Prisma ORM

### Infrastructure
- Docker
- Docker Compose

## Project Structure

- `frontend/`: aplicación web.
- `backend/`: API REST y reglas de negocio.
- `docs/`: documentación y diagramas.
